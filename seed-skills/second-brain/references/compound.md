# Compound a dev fix into the wiki

Use after pd (or other) ticket work when something **reusable** was learned.

Vault root: `~/SecondBrain/Second Brain` (quote it).

## Steps

1. **Decide** — reusable pattern, gotcha, or domain rule? If routine, stop.
2. **Choose target** — default `wiki/projects/pd/gotchas.md`; domain topics → `wiki/concepts/`.
3. **Write** using the gotcha format in the `compound-fix` skill (What / Why / Where / Refs).
4. **Link** — add `[[wikilinks]]` to related concept pages (e.g. [[book-manager]]).
5. **Catalog** — update `index.md` if new page; append `log.md` with `## [DATE] compound | Title`.

## Rules

- Never file "changed line 87" — file the **rule** that line enforced.
- Never edit `raw/` or `projects/` mirrors.
- Full prose in vault; ponytail terse style OK in chat only.
